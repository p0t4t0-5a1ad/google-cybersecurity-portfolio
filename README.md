## 📂 Portfolio Projects & Artifacts

### 1. [Internal Security Audit: Botium Toys](./01-security-audits/)
*   **Objective:** Conducted a comprehensive vulnerability assessment and security audit for a fictional toy company to improve their security posture and compliance.
*   **Skills Applied:** Risk management, compliance frameworks (NIST CSF, GDPR, PCI-DSS), assets classification, and controls assessment.
*   **Key Deliverables:** Executive summary, completed risk assessment checklist, and a remediation mitigation plan.

### 2. [Network Traffic & Packet Analysis](./02-network-security/)
*   **Objective:** Analyzed network logs and packet captures to investigate unauthorized access attempts and potential network-layer vulnerabilities.
*   **Skills Applied:** Packet sniffing, protocol analysis (DNS, HTTP, TCP), and identifying malicious traffic patterns.
*   **Key Deliverables:** Wireshark analysis write-ups, custom `tcpdump` filter commands, and incident mitigation reports.

### 3. [SQL & Linux: Security Log Auditing](./03-linux-sql/)
*   **Objective:** Used Linux command-line utilities and SQL databases to audit user access, modify system permissions, and identify unauthorized login attempts.
*   **Skills Applied:** SQL querying (`SELECT`, `WHERE`, `AND/OR`, `JOIN`), Linux permission management (`chmod`, `chown`), and log parsing (`grep`, `awk`).
*   **Key Deliverables:** SQL scripts for security filtering and Linux terminal command chains for file permission hardening.

### 4. [Python Automation: File Permissions Algorithm](./04-python-automation/)
*   **Objective:** Developed a Python script to automate the process of updating an access control list (allow list) that regulates employee access to restricted medical files.
*   **Skills Applied:** Python scripting, File I/O operations (`.read()`, `.write()`), string manipulation, parsing, and list iterations.
*   **Key Deliverables:** Executable `.py` script and a comprehensive technical write-up detailing the algorithm logic.

### 5. [Incident Response: NIST Framework Case Studies](./05-incident-response/)
*   **Objective:** Responded to and documented mock cybersecurity incidents (e.g., DDoS attacks, malware infections) following standard incident handling lifecycle models.
*   **Skills Applied:** Incident detection, containment, eradication, post-incident reporting, and root-cause analysis.
*   **Key Deliverables:** Incident Handler Journals and formalized Post-Incident Review (PIR) reports mapped to the NIST Incident Response lifecycle.
